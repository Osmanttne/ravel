# Ravel — Presentation Credits

## Product integrations

- **Google Gemini API** — extracts structured observations from user-selected message text and screenshots. The backend uses Google's `google-genai` Python SDK. [Gemini API](https://ai.google.dev/gemini-api/docs) · [Google Gen AI SDK](https://googleapis.github.io/python-genai/)
- **Photon Spectrum** — powers the user-initiated iMessage agent and message routing, using `@spectrum-ts/core` and `@spectrum-ts/imessage`. [Spectrum TypeScript](https://github.com/photon-hq/spectrum-ts) · [Photon](https://photon.codes/)
- **Apple** — iOS app, SwiftUI interface, Share Extension, and iMessage platform. [SwiftUI](https://developer.apple.com/documentation/swiftui/) · [Xcode](https://developer.apple.com/xcode/)

## Frameworks and tools

- **Backend:** Python, FastAPI, Pydantic, Uvicorn, Pillow, and `python-multipart`. [FastAPI](https://fastapi.tiangolo.com/) · [Pydantic](https://docs.pydantic.dev/) · [Uvicorn](https://www.uvicorn.org/)
- **Photon agent:** Node.js, TypeScript, Zod, and dotenv. [Node.js](https://nodejs.org/) · [TypeScript](https://www.typescriptlang.org/) · [Zod](https://zod.dev/)
- **iOS development:** Swift, Xcode, Swift Package Manager, and XcodeGen. [XcodeGen](https://github.com/yonaskolb/XcodeGen)
- **Testing:** pytest, Node's built-in test runner, and Swift/XCTest.
- **AI-assisted development:** OpenAI Codex CLI.
